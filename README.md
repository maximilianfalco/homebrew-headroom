# homebrew-headroom

```sh
brew install --cask maximilianfalco/headroom/headroom-bar
```

| cask | what it is |
| --- | --- |
| [`headroom-bar`](https://github.com/maximilianfalco/headroom) | Menu bar app and widget showing how much of your Claude plan is left |

Not to be confused with the `headroom` cask in homebrew-cask, which is a different app
(Headroom by Headroom Labs, extraheadroom.com).

Version and checksum are written by the release workflow in the app's own repo. Editing them
here by hand will be overwritten on the next release.
